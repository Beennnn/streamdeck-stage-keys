## 3. Listing copy (paste into the wizard)

- **Name:** `Music Instruments for Stage Keys`
- **License:** `CC-BY-4.0` · **Price:** Free
- **Tags:** `music`, `midi`, `instruments`, `keyboard`, `synth`, `general midi`
- **Style:** Illustrated · **Contains AI-generated content:** **YES** (disclose it —
  Elgato allows AI art *with* disclosure; the wizard asks and it is required)

**Description:**

```
Full-colour sound-select icons for the live keyboardist — one Stream Deck key per
voice, covering the complete General MIDI / XP sound set (128 programs, 16 families)
plus modern synth categories and live-rig extras (Vibanet, bass flute, woodwinds
section, six voiced synth leads). Now also includes split-view combo keys: two
instruments on one key for the classic Dual/Layer and Split performances mainstream
keyboards ship (Piano + Strings, Harpsichord + Strings, Synth-Bass / Lead and more).
Every icon has a static and an animated (playing) state. Recognise the sound at a
glance under stage lighting, no menu-diving. Pair with a MIDI plugin (e.g. the free
Midi Button by Tom Kelly, or Trevligaspel's MIDI) that sends Program Change, so each
key both shows and selects the patch. Open-source, built with the sdicons toolkit:
github.com/Beennnn/streamdeck-toolkit
```

  Stage Keys → Versions → the rejected 1.2 → **re-upload the pack above** (now 1.2.0
  with the companion posters that fix the "GIF previews aren't loading" rejection).
